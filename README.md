## Overview

This repository contains my solutions and technical reports for **Assignment 3: Types and OOP Concepts** in the Advanced Software Paradigms course.

The assignment explores fundamental programming concepts through practical implementation. It covers memory allocation in C, static and dynamic binding in C#, and object oriented programming principles in Ruby.
